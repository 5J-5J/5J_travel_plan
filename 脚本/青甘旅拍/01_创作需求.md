# 创作需求 v0.1

建档日期：2026-09-11（北京时间）。状态：需求梳理，等待用户补充制作条件。

## 项目简介

为一次西北青甘大环线旅行创作故事型旅拍视频。音乐使用用户已经挑选的 BGM，故事和镜头组织围绕音乐的情绪与节奏展开。风景参与人物的情绪变化，成片需要有铺垫、变化、释放与余韵。

这是一项原创创作，也是一项可以跨多轮持续修订的制作项目。本文件是创作任务简介；最终交付中还需另写成片故事简介。

## 已明确的要求

| 项目 | 用户要求 |
| --- | --- |
| 地域 | 西北，青甘大环线 |
| 音乐 | 使用 `bgm` 目录内用户选定的音乐；允许截取部分、重组与混音 |
| 叙事 | 故事型旅拍，要有画面和情感上的起伏 |
| 影像 | 电影感；参考 Sam Kolder、Gawx 的视频风格，鼓励想象力 |
| 脚本 | 包含简介，明确景别和时间线 |
| 参考画面 | 可以使用图像生成功能制作 |
| 工作方式 | 开始创作前先理清需求，做好项目仓库同步；支持多次执行 |

音乐截取与混音已获得授权。暂未确认是否引入其他音乐；默认围绕现有音乐和现场声设计。

## 对参考风格的处理

目前仅收到创作者姓名，尚未收到具体参考视频，也尚未完成作品核验。后续将从镜头运动、剪辑密度、现实与想象的衔接、声音设计和叙事结构中提炼适用手法，并转换成这个故事自己的表达。

不把未经核验的作品、镜头或技术归因于具体创作者。参考画面属于概念预演，不代表现场实景、实际天气或当地允许的拍摄方式。

## 待确认的制作条件

以下问题已在对话中发出，答案到达后写入本文件及决策记录。

1. **人物与真实情绪**：出镜人数、人物关系、谁拍谁；希望留住的真实经历或心情；是否由创作方提出完全原创的故事。
2. **时间与路线**：旅行日期、天数、确定目的地、逐日行程。目录名 `2026.10` 不视为已确认的出发日期。
3. **成片形式**：期望片长、横竖屏、发布用途；是否接受旁白和简单表演。提问中的 2–3 分钟、3–5 分钟均为选项，不是已接受规格。
4. **执行资源**：机身/手机、镜头、无人机、稳定器、录音条件；拍摄人员、补拍和摆拍时间。

若后续需要，再补充具体参考视频、剪辑软件、调色/VFX 能力、愿意投入的制作复杂度与必须保留的音乐段落。避免首轮询问过多细枝末节。

## 创作原则（工作建议，尚未锁定故事）

- 用可拍的行动表达人物变化；不要只靠旁白解释情绪。
- 让相同动作、物件或构图在前后出现不同含义，形成可见的情绪回响。
- 先确定音乐段落与叙事功能，再分配镜头长度；并非每个鼓点都必须切镜。
- 安排静止、停顿、现场声及长镜头，让高密度段落有对照。
- 关键镜头需给出现有条件可执行的版本；复杂版本单列。
- 根据真实行程选景；没有确认的景点只作候选。

## 交付验收要求

1. 故事简介清楚说明：主人公是谁、发生了什么、情绪如何变化、结尾如何回应开头。
2. 音乐方案标明原文件版本、原曲入/出点、成片入/出点、拼接方式、停顿与声音设计。
3. 分镜逐镜标明编号、成片时间码、时长、景别、画面动作、镜头运动、情绪/叙事作用、声音、转场、地点与可执行替代。
4. 成片时间线没有非预期空隙或重叠；重叠混音有明确解释。所有原曲时间码落在源文件内。
5. 参考画面以镜号关联到脚本，说明构图意图和实际拍摄差异。
6. 提供按真实旅行日程整理的拍摄清单，区分必拍叙事镜头和可选风景素材。
7. 每次版本都保留变化理由、未解决事项和续接步骤。
